# Despliegue en Vercel

1. Conectar el repositorio de GitHub en [Vercel](https://vercel.com).  
2. Configurar variables de entorno (SUPABASE_URL, SUPABASE_KEY).  
3. Cada push a `master` dispara un despliegue automático.  
4. Ver logs y versiones desde el dashboard de Vercel.  
5. Para rollback, seleccionar un despliegue anterior y “Promote”.
