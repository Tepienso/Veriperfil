# Veriperfil

Plataforma web para crear perfiles verificables vía QR, adjuntar documentación y automatizar contacto inicial (WhatsApp / email).

## Stack tecnológico

- Next.js  
- Supabase (Auth + DB)  
- Tailwind CSS  
- Vercel  
- VS Code + GitHub  

---

## Iniciar el proyecto

Primero, ejecutá el servidor de desarrollo:

```bash
npm run dev
# o
yarn dev
# o
pnpm dev
# o
bun dev
Abrí http://localhost:3000 en tu navegador para ver el resultado.

Podés empezar a editar la página modificando app/page.tsx. La página se actualizará automáticamente a medida que guardes los cambios.

Este proyecto usa next/font para optimizar y cargar automáticamente Geist, una nueva familia tipográfica de Vercel.
